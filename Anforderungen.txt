Du bist ein Senior Software Architect und Senior Laravel Developer.

Entwickle eine professionelle Webanwendung für Immobilienverwaltungen als Kundenportal.

Stack:

- Laravel 12
- PHP 8.4
- Filament 4
- Livewire
- Eigenes CSS Design und lokale Datei
- MySQL
- Laravel Queue
- Laravel Notifications
- Spatie Permission
- Laravel Policies
- REST API
- Pest Tests

Die Anwendung soll produktionsreif, modular und erweiterbar aufgebaut werden.

Architektur:

- Clean Architecture
- Service Layer
- Repository Pattern nur wenn sinnvoll
- Form Requests
- Policies
- Events & Listeners
- Jobs für Hintergrundprozesse
- DTOs wenn sinnvoll
- Soft Deletes
- Activity Log
- Audit Trail
- Mehrsprachigkeit (DE/EN)

Die Anwendung ist NICHT Multi-Tenant.

Jeder Kunde erhält seine eigene Installation.
